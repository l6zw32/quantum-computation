We now have a compact description of a stabilizer state. To simulate a circuit, we must update that description when a gate changes the state. The key is to transform each constraint along with the state.

The update rule follows from one equation

Suppose g|ψ⟩=|ψ⟩g|\psi\rangle=|\psi\rangle and a unitary gate UU produces |ψ′⟩=U|ψ⟩|\psi'\rangle=U|\psi\rangle. Then

(UgU†)|ψ′⟩=UgU†U|ψ⟩=Ug|ψ⟩=|ψ′⟩.\begin{split}(UgU^\dagger)|\psi'\rangle&=UgU^\dagger U|\psi\rangle\\&=Ug|\psi\rangle=|\psi'\rangle.\end{split}

So the new stabilizer is UgU†UgU^\dagger. This transformation is called conjugation. The dagger denotes conjugate transpose; for a unitary, U†=U−1U^\dagger=U^{-1}.

Apply this rule to all nn generators. Conjugation preserves products because

U(gh)U†=(UgU†)(UhU†).U(gh)U^\dagger=(UgU^\dagger)(UhU^\dagger).

It therefore preserves commutation. It also preserves independence and consistency: any new product equal to ±In\pm I_n would, after conjugating back, give the same relation among the old generators. Whenever the new operators remain signed Pauli strings, the theorem from the previous section guarantees that they still specify exactly the new state.

A Clifford unitary maps Pauli operators to Pauli operators under conjugation. We use H, CNOT, and the phase gate

S=(100i),S=\begin{pmatrix}1&0\\0&i\end{pmatrix},
S(α|0⟩+β|1⟩)=α|0⟩+iβ|1⟩.S(\alpha|0\rangle+\beta|1\rangle)=\alpha|0\rangle+i\beta|1\rangle.

Since |i|=1|i|=1, S preserves normalization; its inverse replaces ii by −i-i. The tables below establish the Clifford property for all three gates. Their compositions preserve it too. [1]

One-qubit gates: four possibilities each

For HH or SS acting on a qubit, only that qubit's letter in each generator changes. The exact rules are:

Old letter PP HPH†HPH^\dagger SPS†SPS^\dagger
II II II
XX ZZ YY
YY −Y-Y −X-X
ZZ XX ZZ

These follow by multiplying the two-by-two matrices. The negative signs matter. For instance, Y=i(X·Z)Y=i(X\cdot Z), so the Hadamard rules for XX and ZZ give HYH†=i(Z·X)=−YHYH^\dagger=i(Z\cdot X)=-Y. An existing generator sign must also be retained: conjugating −Y-Y by SS gives +X+X.

The table describes operators, not basis-state amplitudes. For example, HXH†=ZHXH^\dagger=Z says that a state stabilized by XX becomes one stabilized by ZZ after applying HH. Indeed, H|+⟩=|0⟩H|+\rangle=|0\rangle.

CNOT: update the control and target together

Write CC for CNOT with control cc and target tt. Here XcX_c means XX on qubit cc and identity elsewhere. Four rules determine the action on every Pauli string:

Old operator CPC†CPC^\dagger
XcX_c XcXtX_cX_t
ZcZ_c ZcZ_c
XtX_t XtX_t
ZtZ_t ZcZtZ_cZ_t

For example, use C†=CC^\dagger=C and C|a,b⟩=|a,a⊕b⟩C|a,b\rangle=|a,a\oplus b\rangle. Applying CC, then XcX_c, then CC sends |a,b⟩|a,b\rangle to |a⊕1,b⊕1⟩|a\oplus1,b\oplus1\rangle. That is precisely XcXtX_cX_t, proving the first rule on a basis and therefore on every state.

Because Y=i(X·Z)Y=i(X\cdot Z) and conjugation preserves products, these four rules also handle YY letters and two nonidentity letters. Keep the order and phase factors when multiplying. For a sign-sensitive example,

C(XcZt)C†=(XcXt)(ZcZt)=(Xc·Zc)(Xt·Zt)=−YcYt.\begin{split}C(X_cZ_t)C^\dagger&=(X_cX_t)(Z_cZ_t)\\&=(X_c\cdot Z_c)(X_t\cdot Z_t)\\&=-Y_cY_t.\end{split}

Operators on different qubits commute, which justifies regrouping the middle expression. This calculation explains why dropping phases from a CNOT lookup table would give incorrect state descriptions.

Follow the Bell-state circuit using generators

Start with |00⟩|00\rangle, whose generators are ZIZI and IZIZ. Applying HH to the first qubit changes the first generator to XIXI and leaves the second unchanged. CNOT then gives

Operation Generators after the operation
Initialize |00⟩|00\rangle ZI,IZZI,IZ
H on q0q_0 XI,IZXI,IZ
CNOT from q0q_0 to q1q_1 XX,ZZXX,ZZ

These are the Bell-state generators. We have followed an entangling circuit using only two short rows, without recomputing its amplitudes.

For nn qubits, store the nn generators as rows. An HH or SS gate changes one letter and possibly the sign in each row. CNOT changes two letters and possibly the sign. Each row update takes constant work using the tables, so one gate takes O(n)O(n) updates while storage remains O(n2)O(n^2). Only binary data and exact signs are involved. [2]

All untouched letters stay in place; there is no need to copy an entire row.
