We can describe a stabilizer state using nn generators. To simulate a circuit, we must update those generators when a gate changes the state. The key is to transform each constraint along with the state.

The update rule follows from one equation

Suppose g|ψ⟩=|ψ⟩g|\psi\rangle=|\psi\rangle. A unitary gate UU changes the state to |ψ′⟩=U|ψ⟩|\psi'\rangle=U|\psi\rangle. Which operator fixes this new state? Using U†U=IU^\dagger U=I, we obtain

(UgU†)|ψ′⟩=UgU†U|ψ⟩=Ug|ψ⟩=U|ψ⟩=|ψ′⟩.\begin{split} (UgU^\dagger)|\psi'\rangle&=UgU^\dagger U|\psi\rangle\\ &=Ug|\psi\rangle\\ &=U|\psi\rangle=|\psi'\rangle. \end{split}

Thus replace gg by UgU†UgU^\dagger. This transformation is called conjugation. The dagger denotes conjugate transpose; for a unitary, it is also the inverse.

Apply this rule to all nn generators. Conjugation preserves products because

U(gh)U†=(UgU†)(UhU†).U(gh)U^\dagger=(UgU^\dagger)(UhU^\dagger).

Consequently, commuting generators remain commuting. Independence and consistency also survive: any nonempty product of new generators equal to ±In\pm I_n would, after conjugating back, give the same forbidden relation among the old generators. Whenever the new operators remain signed Pauli strings, we therefore retain nn independent, commuting, consistent generators. The previous section's theorem says they specify exactly |ψ′⟩|\psi'\rangle, up to global phase.

Definition (Clifford unitary): A unitary UU is Clifford if UPU†UPU^\dagger belongs to the Pauli group for every PP in that group. This includes the phases +1,−1,+i,−i+1,-1,+i,-i. Conjugation preserves Hermiticity, so our Hermitian generators still have overall signs ±1\pm1.

We use H, CNOT, and the phase gate

S=(100i),S=\begin{pmatrix}1&0\\0&i\end{pmatrix},
S(α|0⟩+β|1⟩)=α|0⟩+iβ|1⟩.S(\alpha|0\rangle+\beta|1\rangle)=\alpha|0\rangle+i\beta|1\rangle.

Since |i|=1|i|=1, S preserves normalization; its inverse replaces ii by −i-i. The tables below establish the Clifford property for all three gates. Their compositions preserve it too. [1]

One-qubit gates: four possibilities each

When H or S acts on a qubit, update that qubit's letter in every generator using this table. A minus sign multiplies the generator's overall sign.

Old letter PP HPH†HPH^\dagger SPS†SPS^\dagger
II II II
XX ZZ YY
YY −Y-Y −X-X
ZZ XX ZZ

For example, the entry HXH†=ZHXH^\dagger=Z says that applying H to a state stabilized by X produces a state stabilized by Z. This agrees with H|+⟩=|0⟩H|+\rangle=|0\rangle.

To derive SXS†=YSXS^\dagger=Y, follow each basis vector through the three operations, starting on the right:

SXS†|0⟩=SX|0⟩=S|1⟩=i|1⟩,SXS†|1⟩=SX(−i|1⟩)=−iS|0⟩=−i|0⟩.\begin{split} SXS^\dagger|0\rangle&=SX|0\rangle=S|1\rangle=i|1\rangle,\\ SXS^\dagger|1\rangle&=SX(-i|1\rangle)=-iS|0\rangle=-i|0\rangle. \end{split}

These are precisely Y's basis actions, so linearity gives equality on every vector. Other entries follow similarly. In particular, Y=i(X·Z)Y=i(X\cdot Z) gives HYH†=i(Z·X)=−YHYH^\dagger=i(Z\cdot X)=-Y. Keep that minus sign, and any sign already present in the generator.

CNOT: update the control and target together

Write CC for CNOT with control cc and target tt. Here XcX_c means XX on qubit cc and identity elsewhere. Four rules determine the action on every Pauli string:

Old operator CPC†CPC^\dagger
XcX_c XcXtX_cX_t
ZcZ_c ZcZ_c
XtX_t XtX_t
ZtZ_t ZcZtZ_cZ_t

To derive the first rule, recall C†=CC^\dagger=C because applying CNOT twice cancels it. For bits a,ba,b, follow CXcC†CX_cC^\dagger from right to left:

|a,b⟩→C|a,a⊕b⟩→Xc|a⊕1,a⊕b⟩→C|a⊕1,b⊕1⟩.\begin{split} |a,b\rangle&\xrightarrow{C}|a,a\oplus b\rangle\\ &\xrightarrow{X_c}|a\oplus1,a\oplus b\rangle\\ &\xrightarrow{C}|a\oplus1,b\oplus1\rangle. \end{split}

The last step uses (a⊕1)⊕(a⊕b)=b⊕1(a\oplus1)\oplus(a\oplus b)=b\oplus1. Both bits flip, exactly as under XcXtX_cX_t. Equality on a basis proves equality on every state.

Because Y=i(X·Z)Y=i(X\cdot Z) and conjugation preserves products, these four rules also handle YY letters and two nonidentity letters. Keep the order and phase factors when multiplying. For a sign-sensitive example,

C(XcZt)C†=(XcXt)(ZcZt)=(Xc·Zc)(Xt·Zt)=(−iYc)(−iYt)=−YcYt.\begin{split} C(X_cZ_t)C^\dagger&=(X_cX_t)(Z_cZ_t)\\ &=(X_c\cdot Z_c)(X_t\cdot Z_t)\\ &=(-iY_c)(-iY_t)=-Y_cY_t. \end{split}

Operators on different qubits commute, which justifies regrouping. The two factors of −i-i produce the minus sign; dropping phases would give the wrong constraint.

Follow the Bell-state circuit using generators

Start with |00⟩|00\rangle, whose generators are ZIZI and IZIZ. Applying HH to the first qubit changes the first generator to XIXI and leaves the second unchanged. CNOT then gives

Operation Generators after the operation
Initialize |00⟩|00\rangle ZI,IZZI,IZ
H on q0q_0 XI,IZXI,IZ
CNOT from q0q_0 to q1q_1 XX,ZZXX,ZZ

The CNOT rules send XIXI to XXXX and IZIZ to ZZZZ, giving the Bell-state generators without recomputing amplitudes.

For nn qubits, store the nn generators in an array, using 2n+12n+1 bits per row. H or S changes one letter and possibly the sign in each row; CNOT changes two letters and possibly the sign. A fixed local lookup table takes constant work per row. Thus one gate costs O(n)O(n) elementary array operations, and storage remains O(n2)O(n^2). Untouched entries stay in place, without copying whole rows. [2]

Check your understanding

1. Two phase gates

Start with the generator +X+X for |+⟩|+\rangle and apply S twice. What generator follows each gate, and what is the final state?

Show answer

The table gives +X↦+Y↦−X+X\mapsto+Y\mapsto-X. The final generator −X-X stabilizes |−⟩|-\rangle, since X|−⟩=−|−⟩X|-\rangle=-|-\rangle. Losing the second update's minus sign would incorrectly return |+⟩|+\rangle.

2. Applying CNOT again

Apply the same CNOT again to the Bell-state generators. Which state results?

Show answer

Conjugation preserves products, so XXXX maps to (XcXt)Xt=Xc(X_cX_t)X_t=X_c, or XIXI. Likewise, ZZZZ maps to Zc(ZcZt)=ZtZ_c(Z_cZ_t)=Z_t, or IZIZ. These generators specify |+⟩⊗|0⟩|+\rangle\otimes|0\rangle, as expected because applying CNOT twice cancels it.

3. A Y on the control

Use the four CNOT rules to compute CYcC†CY_cC^\dagger, including its sign.

Show answer

Since Yc=i(Xc·Zc)Y_c=i(X_c\cdot Z_c),

CYcC†=i(XcXt)Zc=i(Xc·Zc)Xt=i(−iYc)Xt=YcXt.\begin{split} CY_cC^\dagger&=i(X_cX_t)Z_c\\ &=i(X_c\cdot Z_c)X_t\\ &=i(-iY_c)X_t=Y_cX_t. \end{split}

Thus YIYI maps to YXYX with a positive sign. Keeping both phase factors gives i(−i)=1i(-i)=1.

Carry forward: conjugate every generator, keeping its sign. The resulting rows describe the new state exactly. Next we will handle measurement and its random outcomes.
